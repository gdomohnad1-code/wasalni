# خطة بناء تطبيق "وصلني" (Wasalni)

تطبيق نقل ركاب وتوصيل مصري بالكامل بالعربية (RTL)، شبيه بـ Bolt + Uber Eats. سنبني النسخة الأولى الكاملة مع Lovable Cloud (قاعدة بيانات + Auth + RLS).

## الهوية البصرية
- **اللون الرئيسي**: أخضر #00C853
- **مساعد**: أبيض، رمادي فاتح، أسود
- **الخط**: Cairo (Google Fonts)
- **الاتجاه**: RTL كامل + Mobile-first
- **الستايل**: نظيف، حديث، أنيميشن ناعمة (framer-motion)

## المرحلة 1 — الأساس والـ Backend
1. تفعيل **Lovable Cloud** (Auth + DB + RLS).
2. إعداد design system في `src/styles.css`: ألوان، خط Cairo، RTL.
3. جداول قاعدة البيانات:
   - `profiles` (الاسم، الصورة، النوع: راكب/سائق، رصيد المحفظة، كود الإحالة)
   - `user_roles` (rider, driver, admin) — جدول منفصل + `has_role()` security definer
   - `driver_documents` (رخصة قيادة، رخصة سيارة، صورة سيارة)
   - `rides` (نقطة البداية، الوجهة، النوع، السعر، الحالة، السائق، الراكب، التقييم)
   - `wallet_transactions` (شحن، دفع، استرداد)
   - `chat_messages` (رسائل بين السائق والراكب لكل رحلة)
   - `referrals`, `notifications`
4. سياسات RLS لكل جدول.
5. Realtime على `rides`, `chat_messages`, `notifications`.

## المرحلة 2 — Auth والتسجيل
- صفحة دخول/تسجيل: إيميل + كلمة سر (HIBP مفعّل)، Google، Apple، Facebook (الأزرار جاهزة، التفعيل لاحقاً عبر Cloud).
- تسجيل برقم تليفون.
- رفع صورة شخصية إجباري.
- تأكيد إيميل تلقائي (`emailRedirectTo`).
- حساب موحد يقدر يبدّل بين وضع الراكب والسائق.

## المرحلة 3 — واجهة الراكب
- **الرئيسية**: كاروسيل عروض + 5 خدمات (خاصة، مشاركة، طرد، نسائية، VIP) + زر "وصلني الآن". تحذير modal عند اختيار "توصيل طرد".
- **الحجز**: GPS حقيقي (`navigator.geolocation`) + بحث عن وجهة + خيارات (ذهاب/ذهاب وعودة/متعدد).
- **خريطة وهمية SVG** تفاعلية + دبابيس متحركة + عرض المسافة/الوقت.
- **التسعير**: 30 ج.م لأول 3 كم + معامل حسب الخدمة.
- **بطاقة تأكيد** قبل الحجز (تفاصيل + سعر + تأكيد/تعديل).

## المرحلة 4 — الرحلة (3 مراحل)
- البحث عن سائق (loader)
- سائق قابل (اسم، صورة، تقييم، سيارة، "ابدأ الرحلة")
- جاري الرحلة (سيارة متحركة + عد تنازلي + "إنهاء")
- تقييم بالنجوم بعد الانتهاء.
- شات داخلي real-time أثناء الرحلة.

## المرحلة 5 — المحفظة و رحلاتي
- شاشة محفظة: رصيد + شحن + سجل كامل.
- شاشة رحلاتي: سجل + إعادة حجز + كود دعوة (مشاركة/نسخ).

## المرحلة 6 — واجهة السائق
- تسجيل خاص + رفع وثائق (Storage bucket).
- شاشة الرحلات المتاحة (real-time) + قبول/رفض.
- شاشة الرحلات النشطة + الأرباح.

## المرحلة 7 — داشبورد الأدمن
- مستحقات السائقين + سحب.
- الشكاوى والتقارير.

## التفاصيل التقنية
- **Routes** (TanStack Router): `/`, `/auth`, `/home`, `/book`, `/ride/$id`, `/wallet`, `/trips`, `/profile`, `/driver`, `/driver/rides`, `/driver/earnings`, `/admin`, `/chat/$rideId`.
- كل صفحة محمية تحت `_authenticated/`.
- Storage buckets: `avatars` (public)، `driver-docs` (private).
- Realtime channels للرحلات والشات.

## ملاحظات
- **Google/Apple/Facebook Sign-In**: الأزرار موجودة لكن التفعيل الفعلي يحتاج إعدادات في Lovable Cloud لاحقاً (سأخبرك بالخطوات).
- النسخة الأولى ستكون كبيرة جداً — قد أبنيها على دفعات داخل نفس الجلسة، مع التركيز على Flow كامل يعمل من التسجيل → الحجز → الرحلة → التقييم.
